# ADR-001: Money in paise, display in rupees

## Decision

All money is stored and computed as integer paise. Only the presentation
layer converts paise to rupees, through `format_inr` in `billing.py`.

## Rationale

Integer paise avoids float rounding on sums. A single conversion point
means a display bug is a one-line fix, not a hunt through every caller.

## Consequence

Any code that formats a paise value directly as rupees (e.g. an f-string
with `Rs {total}`) is a bug by definition — see TKT-101.
